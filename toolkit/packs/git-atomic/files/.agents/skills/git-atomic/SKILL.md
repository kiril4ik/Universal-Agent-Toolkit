# Atomic Git Workflow

Read `.agent-toolkit/rules/GIT.md` before committing.

Stage only one coherent change set at a time, verify it, and use a specific Conventional Commit-style message. Do not bundle unrelated changes.

Never add `Co-authored-by`, AI/model names, or generated-by trailers unless the human explicitly requests them.
