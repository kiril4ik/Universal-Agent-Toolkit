# Generate / Update Design in Figma

1. Read product requirements, page inventory, content, and existing brand/design-system sources first.
2. Reuse existing Figma components/tokens when available.
3. Generate design only after business logic and required screens are understood.
4. Prefer a coherent system over isolated pretty screens: layout, type, spacing, color, components, states, responsive behavior.
5. Keep realistic content instead of lorem ipsum.
6. When code already exists, capture/inspect the live UI and preserve product behavior while improving visual structure.
7. Validate the resulting design against the requirements and page/user-flow inventory.

**Source:** Figma `mcp-server-guide`, pinned in `vendor/SOURCES.md`.
