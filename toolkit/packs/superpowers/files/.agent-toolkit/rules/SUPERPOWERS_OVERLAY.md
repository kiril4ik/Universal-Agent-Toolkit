# Superpowers Compatibility Overlay

Upstream Superpowers is the conceptual/process source. This project-local adaptation intentionally changes one behavior: **question/approval ceremony is controlled by the toolkit's three interaction modes**.

Direct project/human instructions take precedence over upstream skill ceremony.

- Thorough preserves a high-touch discovery flow.
- Focused asks only material/blocking questions.
- Autonomous resolves normal reversible ambiguity independently and continues.

This does **not** relax destructive, security-sensitive, credential, external side-effect, or production-data safeguards.
