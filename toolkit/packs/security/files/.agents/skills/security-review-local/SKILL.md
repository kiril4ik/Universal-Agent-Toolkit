# Security Review

Read `.agent-toolkit/rules/SECURITY.md`.

For security-sensitive changes, trace trust boundaries and data flows. Review authentication, authorization, input validation, injection/XSS/SSRF, secret exposure, file/path handling, dependency risk, and business-logic abuse. Report evidence and concrete remediation.
